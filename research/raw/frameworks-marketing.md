# Frameworks and marketing lane: adversarial fact-check (2026-09-24)

Checked by re-opening each source (WebFetch, curl, Firecrawl, Open Library API, Internet Archive metadata API). Web search budget was exhausted mid-run, so a few claims could only be checked against the researcher's own URL plus bibliographic records. All wording is paraphrased. Short quotes appear only where the exact words are the fact.

Status key: CONFIRMED = matches a source I opened. CORRECTED = the substance holds but a detail was wrong, so the fixed wording is given. UNVERIFIED = I could not confirm it. REFUTED = the source says otherwise.

## Claims

He calls them a "marketing triangle" in which none works without the other two, and says the only way to get it right is the right message, to the right market, through the right media. Entrepreneur.com ran this as a 2018-07-17 excerpt from *No B.S. Direct Marketing*. He also lays out the three Ms in an archived talk on the Magnetic Marketing site. - https://www.entrepreneur.com/growing-a-business/the-3-ms-of-successful-direct-marketing-campaigns-new/313518 ; https://magneticmarketing.com/blog/06-dan-kennedy-selling-from-the-stage ; https://openlibrary.org/isbn/9781599186252 - The substance is confirmed. The excerpt page does NOT say "3rd edition". It says only *No B.S. Direct Marketing*. The 3rd edition did come out in 2018 (Open Library), so the timing fits, but the label is an inference. A secondary summary (hooshmand.net) calls it the "Results Triangle". No primary source for that name was found.
